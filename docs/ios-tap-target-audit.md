## Implementation decision

Use the existing controls and SwiftUI modifiers. No new shared modifier: it would
hide the label-ordering requirement and could not also solve text-field focus.
The shared segmented control fixes all four callers; the padded fields follow
DepthSearchField's established focus route. No frame, padding, color, layout,
action, or disabled-state changes are intended. `ios/CLAUDE.md` records the convention.

## Verification

Fresh iPhone 17 simulator, iOS 26.5, Staging configuration:

- Baseline: 3 targeted tests, 2 expected failures (email upper-right padding and
  schedule segment upper-left padding), 1 pass (filter trigger edge and sort-row
  trailing whitespace). The failure hierarchy still has ROSTER selected.
- Earlier shared-simulator run suffered a runner SIGKILL; it is not counted as
  product evidence. Retrying on a disposable simulator was authorized.
- `TapTargetAuditFixture` is excluded from device builds and requires both reset
  and deletion-audit launch arguments. It renders the real deletion sheet with an
  inert auth service; it cannot send email, verify a real session, or delete an account.

Run only the ticket's suite:

```sh
xcodebuild -project ios/Depth.xcodeproj -scheme Depth -configuration Staging \
  -destination 'platform=iOS Simulator,id=<disposable-simulator-id>' \
  -parallel-testing-enabled NO -only-testing:DepthUITests/TapTargetUITests test
```

Final run: **6 targeted tests passed, 0 failures**, 100.737 seconds of test execution.
The suite includes a dedicated matching-appearance capture and five interaction tests.

- Email: upper-right (98% width, 15% height) and lower-left (2%, 85%) padding each
  raised the keyboard and accepted the asserted character.
- Deletion code: coordinates 8pt inside the drawn upper-right/lower-left corners
  raised the keyboard and accepted the asserted character. Its accessibility frame
  changes from inner text box to full padded surface with the focus gesture, so the
  test anchors to the fixture's unchanged drawn geometry. The same upper-right
  coordinate failed against the original implementation.
- Segments: upper-left (5%, 15%) and lower-right (95%, 85%) padding selected the
  requested value for page, conference, comparison, and archive switchers. The page
  test also verified Schedule content and returned to the rendered roster.
- Filter trigger: left edge (10%, 50%) opened the sheet. Sort row: trailing whitespace
  (90%, 50%) selected newest. Both passed before any control fixes.
- Six matching before/after captures: page, conference, comparison, archive, email,
  and isolated deletion field. Every channel value below the status bar (first 150
  device pixels excluded) was identical. Full images differed only in the clock
  digits (~0.05% pixels). The deletion fixture deliberately omits the app's outer
  presentation; its standalone chrome is not a product appearance change.
- Independent read-only specialist review: no actionable findings.
