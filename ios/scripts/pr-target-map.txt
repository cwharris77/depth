# pr-target-map.txt — map iOS source files to PR-screenshot capture targets.
#
# Consumed by ios/scripts/suggest-pr-targets.sh. One line per entry:
#   <targets>\t<source-path-prefix>
#
# <targets> is a comma-separated list of capture targets from
# ios/DepthUITests/PRScreenshotsUITests.swift (field, field-footer, formations,
# teams, uniform, player, settings) or the token `all` (= every target).
# <source-path-prefix> is a repo-root-relative path; a changed file matches when it
# equals the prefix or lives under it.
#
# Cost model: one screenshot-check.sh run = one build + one sim boot + one XCUITest
# pass, so extra targets are nearly free. Bias therefore toward MORE targets on
# shared host files (App/, Support/ visuals, Data/, Domain/, the team-detail host)
# and fewer on a specific view's own files.
#
# Files that don't match anything (tests, docs, other features) suggest nothing —
# the caller falls back to the documented default `field`.
