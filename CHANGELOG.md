## [1.0.0] - 2026-09-03

### Added

- iOS app (The Sticks) — interactive NFL depth chart viewer
- SwiftUI native UI with Swift 6 strict concurrency
- SwiftData offline cache with Supabase as source of truth
- Design system with team surfaces, season picker, and player cards
- ESPN and NFLverse data ingestion pipeline
- Cross-language domain fixtures for iOS/web parity
- CI: iOS build/test suite, web format/typecheck/test, screenshot gates
